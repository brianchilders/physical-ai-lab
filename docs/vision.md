# Project Vision

The Physical AI Lab is a reproducible environment for building robotics and embodied-AI systems across simulation, perception, inference, and eventual hardware deployment.

Core goals:

- learn Isaac Sim deeply
- learn OpenUSD while using Isaac Sim
- learn ROS 2 without adding it prematurely
- build reproducible robotics experiments
- integrate local LLMs and vision-language models
- use DGX Spark as a remote inference and experimentation node
- keep every important decision documented

Operating principles:

- documentation-first
- Docker-first where practical
- infrastructure as code where it actually improves reproducibility
- small iterative milestones
- clear separation between tracked source and large local data

The repository should function as:

- a lab notebook
- a system architecture record
- an experiment registry
- a reproducible environment guide
